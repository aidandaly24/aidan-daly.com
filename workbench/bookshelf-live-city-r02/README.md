# Bookshelf City WIP checkpoint

This standalone Three.js prototype is not wired into the production coming-soon page. It drives two temporary articulated residents through five stations without visitor controls. The tested checkpoint uses the original scene art, which is not included in this public source directory. The maintainers' verified private companion archive is `bookshelf-live-city-r02-checkpoint.zip` (SHA-256 `8f7c2b6f39b4174ee08a5b7f067629a0a2da44e9efff154a06b6ab5294474d0c`). Use that complete bundle rather than recreating its art or file hierarchy. It includes Three.js 0.186.1 and its license. Run `node test.mjs && node pose-test.mjs` and serve the bundle with `python3 -m http.server 8765 --bind 127.0.0.1`. Tests verified deterministic simulation and pose continuity; browser/device validation, production character rigs and contact polish are pending. Keep this branch out of production until reviewed.
