# Bookshelf City

Selected design: Bookshelf City, round-two option 06. The source illustration was created for this project with the built-in image tool. The desktop production asset preserves that composition and removes the baked-in companion so the web component can move independently. The portrait asset is an art-directed adaptation retaining all four activities. The actual existing full-name wordmark is reused.

The four Aidan activity poses are illustrative artwork based on the selected concept, not renders of the newer character mesh and not verified skeletal animations. The companion and its trail are implemented web animation. No mesh, Blender source, or third-party model geometry is distributed. The scene registry separates each activity and responsive anchor for future rendered layers or a verified real-time pipeline.

Original asset prompts: remove only the baked star and dotted trail from the desktop scene; adapt the same connected bookshelf world into a portrait layout with all four scenes, a blank headline area, and no baked star or typography. WebP conversion only optimizes delivery.

This entry is staged under /bookshelf/. The production homepage remains unchanged until promotion after review.
